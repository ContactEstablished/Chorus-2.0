## Goal

Friendly shows a panel pinned above the conversation: the session's latest plan across all its turns,
each step with its status, start time and rounded duration, "not timed" where it can't be timed, skill
chips with estimated times, and a folded summary of the current step's tool calls with times. Hide
collapses it to one line, "Now … · Next …". It refreshes on the timeline's existing 1.5 s read, reads
the same after Chorus restarts, and matches the mockup in Glacier and Dusk.

## Acceptance Criteria

- [ ] All commands above pass; `git status` shows only the scoped files and `?? Python/`.
- [ ] In the isolated instance (Overview §7), a Claude Code session in a scratch folder is asked to
  make a 4-step task list, use an installed skill during one step, and mark the last step completed
  without marking it in progress. The panel shows done, current and next steps, rounded durations,
  start times, a skill chip with "~" and an estimate tooltip, and "not timed" on the last step.
- [ ] While a step runs, its time ticks and its tool calls are summarised under it ("Read 2 files ·
  ran …"), with times when unfolded. Hide shows one line "Now … · Next …"; Show restores it.
- [ ] Close and reopen Chorus: the panel reads the same, and the step that was running shows a frozen
  time, not time while Chorus was closed.
- [ ] A session with no plan shows the one-line empty state; per-turn plan boxes still show.
- [ ] Seen in Glacier and Dusk, matching the mockup (spec §5). Codex plan seen too if
  `codex --version` works; otherwise reported as not checked.
